# 自动归类规则

游戏进哪个区块是算出来的。这份是**完整优先级链**与三条例外规则（锁定 / 放弃区 / 批量选择）。

## 自动归类规则（按优先级从高到低）

> 在这之前还有一条**最高优先级**：Steam 收藏夹「**已隐藏**」里的游戏，
> 以及被识别为工具/软件的（Godot Engine、Wallpaper Engine 等），
> 会被强制隐藏，不进任何状态区。可以用总览的「隐藏非游戏」开关控制显示。
> （「已隐藏」也是可改的，见 [收藏夹名字不一样怎么办](faq.md#收藏夹名字不一样怎么办)）

1. **🔒 你锁定的游戏** —— 锁上之后完全不动，连「已通关」也不重算
2. **🗑️ 手动挪进放弃区的游戏** —— 手动终态，同步时同样一动不动
3. **已通关（归档）** —— 在「**已完结**」收藏夹里，或拿了全成就。
   **已通关是终态，永远不会被启动日期挪到其他区**
   （收藏夹名可改，默认认「已完结」）
4. **在「已放弃」收藏夹里** → 自动进「放弃区」（收藏夹名可改，默认「已放弃」）
   ⚠️ 排在 3 **之后**是刻意的：同时命中「已完结」和「已放弃」时**通关赢**
   —— 通关是终态，放弃不是。
   ⚠️ 排在 5、6 **之前**也是刻意的：这一条**不看**玩没玩过、多久没碰，
   收藏夹里写着就是放弃 —— 它跟下面第 8 条**正好相反**。
5. **你手动改的状态（且之后没再启动过）** —— 尊重你的判断，同步不覆盖
6. **90 天内启动过** → 自动进「正在游玩」
7. **超过 90 天没启动** → 自动进「暂停区」
8. **在「待游玩」收藏夹里** → 自动进「待游玩」
   ⚠️ 排在 6、7 **之后**是刻意的：它只接**从没启动过**的款。
   已经玩过的（哪怕很久没碰）不会被拉进来，正在玩的也不会被拽走 ——
   「待游玩」的意思是**想玩但还没开始**。
9. **从未启动过** → 停在「我的游戏单」，等你决定

### 启动日期自动归类（90 天规则）

这是自动分流的**主规则**，看的是 Steam 的「最后启动时间」：

```
最后启动 ≤ 90 天前   →  🔥 正在游玩
最后启动 > 90 天前   →  ⏸️ 暂停区
从未启动（时长 0）   →  留在「我的游戏单」
```

**想改阈值**：`js/store.js` 顶部一个常量搞定：

```js
const RECENT_DAYS = 90;   // 改成 60 就是两个月，120 就是四个月
```

改完需要同步一次（或清空后重新载入）才会全量重算。

#### 手动 vs 自动，怎么区分？

- **自动归类的卡片**：封面左下角有紫色「**自动**」角标
- **你手动设的**：没有这个角标
- 点开卡片能看到具体原因，比如「距上次启动已 117 天（超过 90 天）→ 自动归入「暂停区」」

#### 手动改完不会被覆盖

你手动把某款游戏挪到别处后，只要**没有再次启动过它**，同步就尊重你的选择。
一旦你重新启动了这个游戏，启动时间会更新，「自动」规则重新接管。

> 实现上记两个时间戳：`statusManualAt`（你手动改状态的时刻）与
> `lastPlayedTs`（上次启动）。前者更晚 → 保留手动；后者更晚 → 自动接管。

#### 🔒 锁定：永久钉死某个状态

如果某款游戏你想**永久固定**在某个状态（不管启动日期怎么变），
点开卡片 → 点「🔓 锁定状态」：

- 锁上后，同步时**完全跳过**它 —— 状态一动不动，「已通关」也不重算
- 卡片封面会显示金色「**🔒 锁定**」角标
- 再点一下解锁，恢复自动归类

适合场景：某款游戏你手动归了类，但担心以后哪天启动了又被系统挪走。

#### 🗑️ 放弃区：主动出局

有些游戏你**不会再玩了** —— 停服了、玩腻了、或者当年买亏了。
它们混在「暂停区」里会让那份清单越来越杂。

「放弃区」就是给这些游戏准备的。它**两个入口**，规矩不一样：

**① 收藏夹自动进**（默认认 Steam 收藏夹「已放弃」，可在「设置」里改）

在 Steam 里把这些游戏拖进那个收藏夹就行 —— 同步时它们**直接**进放弃区，
不看玩没玩过、不看多久没碰。

- **能自动放出来** —— 把它们**移出那个收藏夹**，下次同步就回到按日期归类的区块。
  这是放弃区和「已通关」最要紧的区别：**已通关是终态，放弃区不是**。
- **你说了算** —— 要是你在款**还留在**收藏夹里的时候手动把它挪出放弃区，
  应用会记住这次否决，不再自动塞回去（把款移出收藏夹再放回来，否决作废）。
- 同时命中「已完结」和「已放弃」时，**以「已通关」为准**。

**② 手动挪进来**（终态）

- 点开卡片 → 状态按钮里选「🗑️ 放弃区」；
- 或在「暂停区」点「批量选择」一次标一批（见下面「批量选择」）。

手动挪进来的和「锁定」同级：**同步时一动不动** —— 既不会被收藏夹（默认「已完结」）
拉回「已通关」，也不会因为哪天手滑启动了一次就被挪去「正在游玩」。
随时能反悔，点开卡片挪走即可，没有惩罚。

> 卡片左下角有灰色「**🗑️ 已放弃**」角标，鼠标停上去会告诉你是哪种来源 ——
> 自动进来的那句写的是"移到收藏夹外就会自动放回去"。

#### 批量选择（暂停区专用）

在「暂停区」右上角点 **「批量选择」**，界面进入选择模式：

```
[ ⬜ 卡片 ]  [ ⬜ 卡片 ]  [ ⬜ 卡片 ]

已选 4 / 32 款    点卡片选中 · 再点一次取消      [全选] [标为放弃] [退出]
```

- 点卡片 = 勾选 / 取消勾选（**不会**打开详情）
- 「全选」一次勾完当前列表；再点一次变成「取消全选」
- 「标为放弃」把选中的一次性移入放弃区（有二次确认）
- 按 `Esc` 或点「退出」结束选择模式

> 选择模式下切到别的区块会自动退出并清空选择 —— 避免"跨区选中"带来的困惑。

#### 「疑似已放弃」提示

暂停区里有些游戏停了**两年以上**（`js/store.js` 的 `STALE_DAYS = 730`）。
这些卡片左下角会多出一个**虚线样的「疑似已放弃」**角标，提示你去看一眼。

⚠️ **它只是个提示，不会自动归类** —— 你不动它，它就一直在暂停区待着。
觉得确实不玩了，勾上、标为放弃即可。

### Steam 收藏夹怎么读到的

同步脚本会读你**本机 Steam 客户端**的配置文件：

```
<Steam>/userdata/<账号ID>/config/cloudstorage/cloud-storage-namespace-1.json
```

这是本地文件，不需要 API Key，也不受 API 限流影响。脚本会自动探测
Steam 安装目录和账号目录，不用配置。

> ⚠️ 换机器、没装 Steam、或从没登录过该账号时读不到 —— 那时会跳过这一步，
> 其余归类照常工作。
>
> 🔧 **自动探测找不到 Steam 时**（装在非常规位置、绿色版、注册表被清理过），
> 在应用顶栏 **「设置」→ Steam 安装目录** 里手填一个即可，
> 或者点 **「扫描磁盘」** 让它自己找。见
> [Steam 装在哪不一样怎么办](faq.md#steam-装在哪不一样怎么办)。

脚本只负责把**收藏夹名原样**写进数据；「哪个名字代表什么状态」由你自己在
应用里定（顶栏 **「设置」**）。默认认「已完结」「待游玩」「已放弃」「已隐藏」四个名，
其中**只有「已隐藏」是 Steam 自带**的，另外三个（含「已完结」）都是我们自己起的
（你本机没有这些收藏夹时它们什么也不会做）。

### ⚠️ 手动优先

一旦你手动给某个游戏设了状态，**Steam 同步永远不会覆盖它**。

如果你把某个游戏从「已通关」手动挪走，即使它还在「已完结」里，
**下次同步也不会把它拉回去**（除非你先在 Steam 里移出该分类、再加回去）。
